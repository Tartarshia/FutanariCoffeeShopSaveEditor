# Third-party notices

This project uses only the Python standard library and browser platform APIs. No game binaries, extracted assets, save files, or third-party libraries are distributed. Futanari CoffeeShop and Steam remain the property of their respective owners. This is an independent local tool.

The optional Steam achievement feature uses ctypes to load the Steam API DLL
from the user's own installed game. The DLL and Steamworks SDK are not included.
Steam client access requires the user to own the game and be logged in. The
bridge was independently implemented against the documented native API.
